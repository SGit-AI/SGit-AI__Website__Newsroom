# 02: `/status.json`: the one file we ask for

A small JSON file at the root of your site. It is regenerated by your build every release, and it is
deterministic from your data and VERSION, the same as your pages. The newsroom's front-page strip and
its tracker read it. Everything in it should already be in your `data/` files; this file gathers it in
one place, under a contract that will not move when your data layout changes.

## Shape

```json
{
  "schema": "newsroom-story-status/1",
  "site": "https://php.oct.2026.newsroom.sgit.ai/",
  "story": "php2shell",
  "title": "php2shell: the two PHP flaws of October 2026",
  "dek": "One or two sentences, plain, for a front page strip.",
  "status": "developing",
  "version": "0.2.3",
  "released": "2026-10-22",
  "data_as_of": "2026-10-22T11:34Z",
  "vault_commit": "200d08971937",
  "counts": {
    "sources": 184, "captures": 177, "hashed_files": 855,
    "claims": 70, "events": 68, "agencies": 16, "inventory": 674
  },
  "headline_facts": [
    {"text": "Two flaws, CVE-2026-109618 and CVE-2026-109619, CVSS v4.0 9.2, fixed in PHP 8.5.12, 8.4.27, 8.3.36 and 8.2.35.",
     "status": "confirmed", "url": "https://php.oct.2026.newsroom.sgit.ai/flaws/index.html"}
  ],
  "pages": {
    "front": "https://php.oct.2026.newsroom.sgit.ai/index.html",
    "sources": "https://php.oct.2026.newsroom.sgit.ai/sources/index.html",
    "timeline": "https://php.oct.2026.newsroom.sgit.ai/timeline/index.html",
    "numbers": "https://php.oct.2026.newsroom.sgit.ai/numbers/index.html"
  },
  "supersedes": ["https://newsroom.sgit.ai/php-flaws/index.html", "https://newsroom.sgit.ai/php-flaws/sources.html"]
}
```

## Rules

- `status` is one of `developing`, `settled` and `archived`. The newsroom shows the strip while it is
  `developing`.
- `data_as_of` is the time of the latest capture your data was exported from, not the build time. Your
  build has no clock, and this keeps it that way.
- `headline_facts`: zero to three, each a claim already on your site, with its status word and a link to
  where it is backed. The newsroom may show the first one in the strip, word for word.
- `counts`: only counts your site already shows. Leave a key out rather than guess.
- `supersedes` lists the newsroom pages you replace. The newsroom checks that it is there before it
  retires them.
- Keep the file under 8 KB. Add your gate's credential-shape check to it, like every other output.
