Versions of the page for publishers

The page for publishers has a version history, the way every article on this site has one. Its text changes when the editor decides it should, and every version is kept as it was published, with what changed. Its live parts, the features and the newest articles, change on their own in every release; those changes are recorded too.

The current text is v2.0.0, of 2026-10-18. The page as it is now.

A change to the text is the next minor version; a rewrite is the next major, the editor's call. The build will not publish a changed text without a new version: admin/content/publishers/versions.json records the sha256 of the source each version was built from. Each version is frozen as markdown, live parts included, by the release that made it, and never rewritten.
