One correction, found in the checking

issues-fs.sgit.ai's own network page lists a sibling as sentinel.sgit.ai. Its actual repository — SGit-AI__Website__SG-Sentinel — ships a CNAME file reading sg-sentinel.sgit.ai. The likely explanation is ordinary: issues-fs.sgit.ai's network page predates SG-Sentinel's own release, written when the name was provisional, and nobody has gone back to correct it since. This is exactly the drift a Librarian role exists to catch — not an accusation against issues-fs.sgit.ai, whose own house convention is to publish corrections rather than hide them, but the first live example of why this site's sourcing rule (read the named site's own repository, not a sibling's claim about it) is not a formality.

One piece of lineage, while checking sgit.ai's own history

sgit.ai's release notes for v0.2.39 record that its validate → tag → deploy pipeline — the same three-stage pipeline this site ships in v0.1.0 — was “ported from the VoiceDebrief website pipeline.” Every git-native *.sgit.ai site built since has carried the same pipeline forward with the same fixes intact (the SIGPIPE-under-pipefail fix, the merge-commit anchoring for pull-request releases). This site's own admin/ page states that lineage rather than presenting the pipeline as newly designed.

How each number was checked

Every version and hostname above was read directly, on 22 August 2026, with the two commands below run once per repository. No number on this page was copied from another *.sgit.ai site's own footer or network table.

curl -s https://raw.githubusercontent.com/SGit-AI/<repo>/dev/CNAME
curl -s https://raw.githubusercontent.com/SGit-AI/<repo>/dev/admin/build/version.txt
# sgit.ai has no admin/build/version.txt; its version is SITE_VERSION in
# admin/build/build_pages.py, checked the same way

This is a snapshot. Every one of these sites publishes to its dev branch on every release; by the time you read this, several of the numbers above are almost certainly out of date. Re-check the source before repeating one.

For an agent

This story is a snapshot taken 22 August 2026. Every version number in the table has a named source repository and a checked-against method above — re-run those two curl commands against the current dev branch before treating any number here as live. sg-sentinel.sgit.ai is the corrected hostname for that sibling; sentinel.sgit.ai, seen on an older page elsewhere in the network, is not current.
