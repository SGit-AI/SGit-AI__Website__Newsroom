Definitions (3)

  • definitionMXC is an SDK the host builds in: a JSON request names the container type, the rules and the command; MXC validates it, picks a backend and launches the workload in a container, with the policy held outside the workload.“The policy is held outside the workload, so the agent, or code it generated, cannot grant itself more.” § briefing
    Microsoft Execution ContainersIsolation and agent desktops 28Hope or enforcement 65
  • definitionThe Agent Control Specification is a portable manifest that evaluates a policy, usually Rego, at eight interception points in the agent loop with a session snapshot, returning allow, warn, deny or escalate and failing closed.“runs a policy engine (usually Rego), and returns allow, warn, deny or escalate, failing closed if anything breaks” § briefing
    Agent Control SpecificationOpen Policy Agent 7Hope or enforcement 65
  • definitionCloud providers drew a line where their control ended, security of the cloud theirs and security in the cloud yours; platforms for agents draw the same line at the granularity they can touch, not out of bad faith.“A company draws its responsibility around what it can touch. That is not bad faith.” § shared
