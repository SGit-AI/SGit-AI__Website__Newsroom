Hypotheses (2)

  • hypothesisThe owner's working picture is that models build enormous multi-dimensional graphs of how language connects, and a prompt is a kind of real-time fine-tuning that pulls the graph towards the part you mean.“My working picture is that these models build enormous multi-dimensional graphs of how things in our language connect” § models
    Models as mirrorsMeaning through connectivity 24
  • hypothesisA world in which every agent runs on one model with one set of behaviours is the same monoculture; many agents from many models, each bounded by its own published policy, is healthier.“A world in which every agent runs on one model, with one set of behaviours, is the same monoculture.” § diversity
