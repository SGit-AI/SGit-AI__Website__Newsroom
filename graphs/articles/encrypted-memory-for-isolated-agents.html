Facts (20)

  • factIsolation takes away the shared drive and ephemeral compute takes away the disk, so whatever an isolated agent learned has to be written somewhere that outlives it.“Isolation takes away the shared drive, and ephemeral compute takes away the disk.” § top
    Isolation and agent desktops 28Memory and context 46
  • factThe memory has to meet three conditions: the owner controls it, the agent can reach it with a credential that can be scoped and revoked, and a breach of where it is stored exposes nothing.“A breach of the place it is stored exposes nothing, because that place is the one most likely to be shared” § top
    Memory and context 46Encryption and keys 70
  • factThe access token gates every route, reads included, through a header, and without it the server answers 401; storage is disk, s3 or memory.“Without it the server answers 401.” § top
    Identity and secrets 59Deployment and self-hosting 21
  • factThe deployment docs still say an endpoint flag in three places; sgit 0.20.0 rejects it, so the base-url flag is the one to use.“sgit 0.20.0 rejects that flag, so use --base-url.” § top
    sgit 91sgit.ai 62
  • factThe newest mcp package, 2.3.0, breaks the server at start-up when installed from pip, and pinning mcp below 2 fixes it.“The newest mcp package, 2.3.0, breaks the server at start-up” § top
    sgit 91Deployment and self-hosting 21
  • factThe agent entry-point script, run outside a container against the local server, cloned a scoped folder, appended to the agent's notes, committed and pushed, and a full clone elsewhere pulled the change.“it cloned, appended to the agent's notes, committed and pushed” § top
    sgit 91Memory and context 46
  • factThe backup of every agent's memory is a copy of one folder, and what is copied is ciphertext, so the backup does not have to be trusted with the contents.“what you are copying is ciphertext, so the backup does not have to be trusted with the contents” § top
    Encryption and keys 70Incidents and resilience 25
  • factA scoped clone is not an access boundary: the clone of one agent's folder fetched another's a moment later, because the vault key opens the whole vault and the path flag decides only what is downloaded.“--path decides what is downloaded, not what can be read.” § top
    Vault design 48Encryption and keys 70
  • factOn Kubernetes the server is a Deployment with one replica, a PersistentVolumeClaim, a ClusterIP Service and a Secret, and the agents are Jobs that clone, work, commit and push behind a NetworkPolicy.“The vault server is a Deployment with one replica, a PersistentVolumeClaim mounted at /data” § top
    Kubernetes 3Deployment and self-hosting 21
  • factA vault is not tied to the server it was created on: it is a set of encrypted objects addressed by hash, any clone holds them, and the same vault can live on two servers.“A vault is not tied to the server it was created on.” § top
    Incidents and resilience 25Vault design 48
  • factIn the test a push to a second remote gave a clone with every file; after a restart emptied the memory-mode server, one more push re-synced it and a fresh clone came back at the same commit.“One more sgit push --remote backup from any clone re-synced the vault” § top
    Incidents and resilience 25sgit 91
  • factThe servers do not replicate to each other; the copies are as fresh as the last push to each, so a push to the backup remote has to be scheduled or done by the agents.“The servers do not replicate to each other.” § top
    Incidents and resilience 25
  • factThe stored files are encrypted objects named by hash, encrypted keys for the clone branches, refs, and a manifest with the vault id, a hash of the write key and the creation time.“zero matches for any of them” § top

  • factAn attacker who takes the storage, the instance, the bucket or the backup gets vault ids, object counts, sizes and timing, not the contents, the names or the keys, but can still delete things.“Not the contents, not the names, not the keys.” § top

Proposals (4)

  • proposalStart with a Mac mini: the vault container next to the agent containers, its storage in a local folder, no cloud account and no public address.“This is where I would start, and where I suggest you start.” § top
    Mac miniDocker 8Deployment and self-hosting 21
  • proposalIf an agent must not read another agent's memory, give each agent its own vault, and read keys, which cannot write, for anything it only needs to read.“If an agent must not read another agent's memory, give each agent its own vault” § top
    Encryption and keys 70Isolation and agent desktops 28
  • proposalIn the cloud the server sits inside the VPC behind an internal load balancer with a private address, storage in S3 through a VPC endpoint, the Mac mini joining over a VPN and CloudFront for a stable name.“an internal load balancer with a private address only, the vault server behind it, storage in S3 through a VPC endpoint” § top
    Amazon Web Services 30Deployment and self-hosting 21Mac mini
  • proposalAdd a second remote once the memory matters and push to it on a schedule; treat the cloud templates as in progress and the Docker image as the part that is ready.“Add a second remote once the memory matters, and push to it on a schedule.” § top
    Incidents and resilience 25Deployment and self-hosting 21
