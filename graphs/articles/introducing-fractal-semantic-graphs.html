Hypotheses (2)

  • hypothesisNaming edges used to be the expensive part and is now the cheap part, because a language model can propose the verb between two nodes faster than a human can type it, so the bottleneck moved to deciding what the graph is for.“Naming edges used to be the expensive part. It is now the cheap part.” § top

  • hypothesisThe schema wars are over because nobody won; the only integration model that survives is one where nobody is asked to conform and everybody is allowed to connect.“And the schema wars are over, because nobody won.” § top

Definitions (4)

  • definitionA semantic graph gives the edges meaning: every edge is a verb and every verb has a named inverse, so a link reads correctly from whichever end you stand at.“A semantic graph gives the edges meaning: every edge is a verb, and every verb has a named inverse” § top
    Fractal semantic graphs 62Meaning through connectivity 24
  • definitionA fractal semantic graph has no privileged level and no single schema; zooming into any node enters a new world with its own node types, verbs, taxonomy and centre of gravity.“A fractal semantic graph has no privileged level and no single schema.” § top
    Fractal semantic graphs 62
  • definitionThe test for the word: a system that never lets you leave one vocabulary is a single graph or a hierarchy; the fractal property is that on one link you can jump into another universe.“The fractal property is that on one of those links you can jump into another universe.” § top
    Fractal semantic graphs 62
  • definitionThe grammar is five rules: every edge is a verb stated in both directions with an inverse; relates_to is banned; properties carry data, never meaning; supersede, never delete; render the answer to a question, never the whole graph.“What none of them gets to change is the grammar, and the grammar is five rules.” § top
