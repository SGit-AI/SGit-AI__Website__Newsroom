Hypotheses (2)

  • hypothesisHooks are the sweet spot for now: the first layer that does not depend on the model, and the last that still sees the action as the agent meant it, a tool call by name, a commit with its message.“They are the first layer that does not depend on the model: the same input gets the same answer every time, at no model cost.” § layers
    Agent tooling 32Hooks are kernel code 14Hope or enforcement 65
  • hypothesisWe already need this for our own agents, which is the best reason to build it; a session with a written policy and a release process can be among the heaviest users of hooks, and every gap found is one a customer does not.“We already need this for our own agents, which is the best reason to build it.” § pack

Proposals (4)

  • proposalA hook pack should be a set of independent checks, one small hook per rule with one job, where the most restrictive answer wins, not a pipeline where one hook depends on another's output.“A hook pack should be a set of independent checks, not a pipeline.” § chained
    A hook pack generated from a policyAgent tooling 32
  • proposalThe useful contribution to OWASP is not a new project on hooks but real policies and real hooks to test the existing standard with.“one exists, and the useful contribution is real policies and real hooks to test it with.” § who
    OWASP 13Agent Control Standard 2A hook pack generated from a policy
  • proposalThe whole loop to build: from the written policy, one row per rule, generate one hook per row with fixed inputs that must be allowed and blocked as tests, install the pack where the agent cannot write, then read the pack back against the policy.“every rule with no hook is still hope, and every hook with no rule is a control nobody can explain.” § pack
    A hook pack generated from a policyBehaviour policy 91Hope or enforcement 65
  • proposalThe description stays the source, as Sean Turner's control for skills does: change the rule, regenerate the hook, rerun the tests; and since a hook answers allow, deny or ask like a gateway, the same rows can later be compiled for the gateway.“change the rule, regenerate the hook, rerun the tests.” § pack
    A hook pack generated from a policySean Turner 2Agent tooling 32
