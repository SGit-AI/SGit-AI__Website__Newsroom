Hypotheses (2)

  • hypothesisIn most images the code the application never runs is the large majority, and every one of those files is attack surface.“My estimate is that in most images it is the large majority” § bottom-up
    The code you do not ship 18
  • hypothesisChainguard is unusually well placed to offer the certified top-down build and should build it or partner with whoever does, since built on top of their platform it could eventually deploy without the base images.“which is why I think they should build it, or partner with whoever does” § certify
    Chainguard 8The code you do not ship 18

Proposals (3)

  • proposalCome from the other end and ask one question at every layer: what is the minimum code below this that the layer above needs; keep that and remove everything else.“what is the minimum code below this that the layer above needs?” § top-down
    The code you do not ship 18The immutable line
  • proposalFunction-level removal would cut much more than file-level, and that is where a semantic graph of the code, function by function, earns its place.“Function-level removal would cut much more than file-level” § limits-measured
    Fractal semantic graphs 62The code you do not ship 18
  • proposalIn a build that keeps only the code a use case needs, a vulnerability in removed code is a line in the record saying the code is absent, which a third party can certify.“it is a line in the record saying the code is absent” § certify
    The code you do not ship 18Provenance and evidence 99Supply chains 22

Definitions (1)

  • definitionThe immutable line is the level below which nothing changes; the higher it is drawn, the more of the system is fixed, exact and small.“The higher you can draw the line below which nothing changes, the immutable line, the more of the system is fixed, exact and small.” § top-down
    The immutable line
