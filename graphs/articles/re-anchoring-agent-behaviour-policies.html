Definitions (3)

  • definitionRe-anchoring: the rules live in an Agent Behaviour Policy file and a hook prints the file back into the context after every summary, verbatim, so the rules are restored, not remembered.“The rules are restored, not remembered.” § top
    Memory and context 46Behaviour policy 91Agent tooling 32
  • definitionThe canary is the second half of the technique: a short status report, computed from the transcript, at the end of every few answers; if it stops appearing, something in the policy has not been read.“So the second half of the technique is a canary.” § top
    The canaryBehaviour policy 91

Decisions (4)

  • decisionThis session runs a SessionStart compact hook, a UserPromptSubmit hook and a Stop hook, each calling abp.py; the reanchor step prints a header naming the policy version and hash, then the policy, and logs that it ran.“then the policy, and logs that it ran” § top
    Agent tooling 32Behaviour policy 91Claude Code 49
  • decisionThe model does not write the numbers: the UserPromptSubmit hook computes the report from the transcript and the harness's cost record, because a report the model wrote from memory would be one more thing to verify.“A report the model wrote from memory would be one more thing to verify.” § top

Limits (5)

  • limitRe-anchoring does not change a rule's barrier: an expectation stays a rule in prose enforced by nobody; what changes is that it is reliably in view, the precondition for everything else.“What changes is that the expectation is reliably in view, which is the precondition for everything else.” § top
    Behaviour policy 91Hope or enforcement 65abp.sgit.ai 23
  • limitRe-anchoring does not enforce anything; it keeps rules in view, and a rule in view is still an expectation.“Re-anchoring does not enforce anything.” § top
    Memory and context 46Hope or enforcement 65
  • limitThe canary is a setting, not a boundary: it lives in a settings file the session could edit, and it cannot stop an agent that decides to ignore the policy.“The canary is a setting, not a boundary.” § top
    The canaryHope or enforcement 65
  • limitA report can be pasted without the rules being followed; it shows the hooks fired and measures what the transcript can measure, and for the rest you need a reader or a gate.“A report can be pasted without the rules being followed.” § top

  • limitThe summaries stay a black box: re-anchoring does not show what a summary kept, it makes what matters independent of it.“The summaries stay a black box.” § top
