Facts (15)

  • factSean Turner built a natural-language control policy for agent skills and a CI pipeline that checks every skill contributed to an organisation-wide repository against it before hundreds of developers pull it down.“a natural-language control policy for agent skills” § top
    Sean Turner 2Behaviour policy 91Agent tooling 32
  • factThe control asks whether a contributed skill is safe, secure, well documented, usable, understandable by the model that loads it and by the people who review it.“is it safe, is it secure, is it well documented, is it usable” § built
    Behaviour policy 91Sean Turner 2
  • factWhat makes it more than a linter is that it reads the skill in its context: a LinkedIn skill working from internal documents has no prompt injection risk, a skill that pulls content off the internet reads untrusted text.“What makes it more than a linter is that it reads the skill in its context.” § built
    Prompt injection 26LinkedIn 20Behaviour policy 91
  • factThe control is complementary to a security scan, not a replacement: a scanner asks whether a skill is malicious, the control asks whether this is the right way to give the skill to the workforce.“it is complementary to a security scan, not a replacement for one” § built
    Behaviour policy 91
  • factThe owner describes the tool as Sean described it; he has not seen the code and could not find it published.“I have not seen the code, and I could not find it published.” § built

    Chainguard 8Supply chains 22Behaviour policy 91

    The lethal trifecta 11Simon Willison 8Behaviour policy 91
  • factA written control is still far better than none: it is the only place the intent exists, what a reviewer reads, what a model checks against, and what the deterministic rules are written from.“A written control is the only place the intent exists.” § hope
    Hope or enforcement 65Behaviour policy 91

Proposals (2)

  • proposalSean's next step: use an agent to write deterministic rules that follow the natural-language control; the model reads the control once and writes code that then runs the same way every time at no model cost per run.“Use an agent to write deterministic rules that follow the natural-language control.” § codify
    Use models to need them lessSean Turner 2Hope or enforcement 65
  • proposalBring hundreds of skills to a common ontology, as fractal semantic graphs do, so that which skills read untrusted content, reach private data and can send it out becomes a query rather than a review.“Then the questions that matter across a catalogue are queries, not reviews.” § graph
    Fractal semantic graphs 62The lethal trifecta 11Agent tooling 32

Definitions (2)

  • definitionA skill described as an agent behaviour policy has a mandate, what it is for; a reach, everything it touches; a gap, which is the risk; and a barrier in front of each row of the gap.“Describe a skill that way and the context question answers itself.” § abp
    Behaviour policy 91Reach 47
  • definitionA control written in natural language and checked by a model is hope-based security: you give the model the rule and hope it follows it.“A control written in natural language, checked by a model, is what I call hope-based security.” § hope
    Hope or enforcement 65

Decisions (1)

  • decisionThe description stays the canonical version, not the code: if the control changes, change the description and regenerate the code.“the description stays the canonical version, not the code” § codify
