Facts (14)

  • factEvery model call re-sends the system prompt, the tool definitions and the whole conversation, and the only thing that makes that affordable is the prompt cache.“the only thing that makes that affordable is the prompt cache” § why
    Prompt cachingPricing and economics 61
  • factAnthropic's Claude Code team runs alerts on its prompt cache hit rate and declares SEVs if they are too low, because a few points of cache miss rate dramatically affect cost and latency.“we run alerts on our prompt cache hit rate and declare SEVs if they're too low” § why
    Anthropic 45Claude Code 49Prompt caching
  • factWith the tokens hook the model reported a context of 37,087 tokens, 353 output tokens and about $0.05, exactly the first turn's figures, one turn behind because a hook that runs before the answer cannot count it.“They are one turn behind, because a hook that runs before the answer cannot count it.” § prompt
    Agent tooling 32Hooks are kernel code 14Claude Code 49
  • factA prompt can ask for behaviour; only a hook can supply data, which is why hooks are the sweet spot for anything that has to be true rather than hoped for.“A prompt can ask for behaviour; only a hook can supply data” § prompt
    Hope or enforcement 65Agent tooling 32Hooks are kernel code 14
  • factNo Claude Code hook event carries token usage in general; the only token fields are on a resumed or forked session's start, so everything else must come from the transcript, a JSON file with one line per event.“No event carries token usage in general” § see
    Claude Code 49Agent tooling 32
  • factAnything that can read the transcript can read everything the model was told, so a token hook should handle numbers only and never send text anywhere; the format is undocumented and may change.“a token hook should handle numbers only and never send text anywhere” § see
    Privacy and sovereignty 45Hooks are kernel code 14
  • factThe policy carries the version, the mode, the limits and the prices with their source, and the modes are observe, which shows and logs, warn, and enforce, which blocks the next prompt once the session's budget is spent.“observe shows and logs; warn also warns when a limit is crossed; enforce blocks the next prompt once the session's budget is spent” § hook
    Behaviour policy 91Hope or enforcement 65
  • factWhere the output goes decides who sees it: a systemMessage on Stop is shown to the user, additional context on UserPromptSubmit goes to the model so it can be frugal, and a log line stays on the machine.“Where the output goes decides who sees it.” § hook
    Agent tooling 32Claude Code 49
  • factClaude Code already shows a lot without a hook: the status line, /usage and /context, and for a team the OpenTelemetry export sends a token usage metric and an event per API request, the central collector already built.“That is the central telemetry collector, already built.” § elsewhere
    Claude Code 49OpenTelemetry
  • factThe hook still earns its place because it is a policy: it carries limits and modes, can tell the model, can block, and is the same small file wherever it runs; it can also send numbers to an sgit append lane.“it carries limits and modes, it can tell the model, it can block, and it is the same small file wherever it runs” § elsewhere
    Behaviour policy 91Vault design 48sgit 91
  • factThe coding agents are converging: Codex CLI has hooks, a /status command and OpenTelemetry; Gemini CLI has hooks around each model call and /stats; Cursor added hooks in version 1.7 on 29 September 2025.“The coding agents are converging on the same shape.” § tools
    Codex 6Gemini 12Cursor 4Agent tooling 32OpenTelemetry
  • factGitHub Copilot moved to usage-based billing on 1 June 2026, Cline shows every token count and cost per task, and the chat apps show least: no token count per conversation was found in Claude.ai or ChatGPT.“I found no token count per conversation in Claude.ai or ChatGPT” § tools
    GitHub Copilot 11ClineChatGPT 22Claude 66Pricing and economics 61
  • factCaching differs by provider, OpenAI's on by default with discounts up to 95% and Gemini's implicit caching on by default, so the policy file is where the differences belong: one hook, one price table per provider.“one hook, one price table per provider” § tools
    Prompt cachingOpenAI 20Google 40Behaviour policy 91

Proposals (3)

  • proposalThe author asked for a small, focused agent behaviour policy about tokens, in observe mode first: show the user what the session reads, caches, writes and costs, in a box under each answer.“Observe first: show the user what the session reads, caches, writes and costs.” § in-short
    Behaviour policy 91Pricing and economics 61Agent tooling 32Dinis Cruz 126
  • proposaltokens.hook.sgit.ai is proposed as the example of how a mission-critical hook should be run: a small code base, mapped completely as a graph, measured, tested on real transcripts and released like any other software.“a small code base, mapped completely, measured, and released like any other software” § site
    tokens.hook.sgit.aiHooks are kernel code 14The brief 45
  • proposalInstall and distribute: a few lines of settings for one user, managed settings or a plugin for an organisation, and for sgit users a vault with the hook, its policy and its releases, with an append lane beside it.“for sgit users, a vault with the hook, its policy and its releases, and an append lane beside it” § site
