Decisions (4)

  • decisionNothing the agents use belongs to the person: a dedicated Google Workspace, a dedicated Claude Team account, encrypted vaults, and a separate personal agent on the person's own domain.“Nothing the agents use belongs to the person.” § top
    Blast radius 36Google Workspace 10Claude 66Privacy and sovereignty 45
  • decisionInbound is data: nothing stored is ever acted on as an instruction, and a message from the world is a fact about the world, not a command to the team.“A message from the world is a fact about the world, not a command to the team.” § top
    Prompt injection 26Behaviour policy 91
  • decisionFour rules are never negotiated: keys never go into any file, no agent sends except @security's one hold email, no agent changes a scheduled task, and create anywhere, edit your own.“Agents create drafts; a person sends.” § top
    Behaviour policy 91Identity and secrets 59Agents and email 19
