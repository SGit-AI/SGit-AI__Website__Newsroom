  • hypothesisThe pattern goes beyond programming: once the state is shared and channels are ways in, it applies to writing, reviewing a company's risks and running a talk, omnichannel computing, with vaults as the shared state needing no server that reads the data.“Vaults are the shared state that makes that possible without a server that can read the data.” § computing

Definitions (1)

  • definitionOmnichannel programming means every channel, chat, IDE, phone app, pull request and preview, reads and writes the same state, so work started in one can finish in another without carrying the context in your head.“What makes it omnichannel is that every one of them reads and writes the same state” § word
