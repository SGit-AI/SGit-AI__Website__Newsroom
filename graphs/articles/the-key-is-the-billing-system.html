Hypotheses (1)

  • hypothesisWhat stopped the project was not a server; it was the lack of one, because the commercial model needed something the terms would not allow without a backend.“What stopped it was not a server. It was the lack of one.” § noserver

  • proposalThe ask to every provider is one sentence: let the credit limit be a property of a key that a user can buy through us, so that we never hold the audio and never run the meter.“let the credit limit be a property of a key that a user can buy through us, so that we never hold the audio and never run the meter” § brief
