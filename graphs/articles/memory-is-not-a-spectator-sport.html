Hypotheses (3)

  • hypothesisThe industry's picture of agentic memory is one store that everything is pumped into and retrieved from by similarity; the owner's is the opposite, and that picture is wrong in three related ways.“I think that picture is wrong in three ways, and the three are related.” § top
    Memory and context 46
  • hypothesisIt is many memories, not one, because context is specific; by now the memories across the estate are inconsistent in places, and that is the point, since a memory forced to agree with all the others would be wrong for every one of them.“I used to think that was a problem to solve. I now think it is the point” § top
    Memory and context 46Fractal semantic graphs 62
  • hypothesisBeing open matters more than people expect: open source and Creative Commons let an agent fetch, quote, link and clone the memory, and the more is published the less the next session has to be told.“The more I publish, the more there is for the next session to stand on, and the less it has to be told.” § top
