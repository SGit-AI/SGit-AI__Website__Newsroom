    The vault 108The SGit Newsroom 72sgit 91

    The vault 108The SGit Newsroom 72

    Vault design 48sgit 91

  • data-pointAfter the fix, fetching the whole head into an empty store takes about three minutes, down from about 53; a pull with nothing new takes 2.5 seconds. 3 minutes to fetch the whole head into an empty store“takes about three minutes, down from about 53” § session
    sgit 91Vault design 48
  • data-pointWith the same 35,000 objects on local disk, the one-folder, one-commit clone fell from 13 seconds to 2.3 with a plain file server and 0.8 with the API server as a local process. 0.8 seconds for one folder, one commit, from local disk“The one-folder, one-commit clone fell from 13 seconds to 2.3 and 0.8.” § storage
    sgit 91Deployment and self-hosting 21
  • data-pointThe ruv.sgit hive runs say the same from the other side: on a local server every sgit operation in fifteen recorded runs took between 0.4 and 1.5 seconds, including starting Python and deriving the key. 15 recorded hive runs“every sgit operation in fifteen recorded runs took between 0.4 and 1.5 seconds” § storage
    ruv.sgit.ai 8sgit 91
  • data-pointEarlier measurements on a single local server process found ten clones of one folder at once took 1.9 seconds with the server mostly idle, while ten full clones queued to 21 seconds. 1.9 seconds for ten simultaneous one-folder clones“ten clones of one folder at once took 1.9 seconds with the server mostly idle” § many

Hypotheses (1)

  • hypothesisVaults of this size are where sgit becomes useful for more than agents' memory, including source code.“I think vaults this size are where sgit becomes useful for more than agents' memory, including source code” § code

Proposals (2)

  • proposalThe fix for the history walk is designed: a small encrypted record of the commit chain, written on every push, so a clone can fetch the chain in about 26 batched requests instead of discovering it.“a small encrypted record of the commit chain, written on every push” § fetch
    Vault design 48sgit 91
  • proposalThe next test the owner wants is a real code base moved into a vault, with agents working on it, each cloning the one package it works on in seconds.“a real code base, moved into a vault, with agents working on it” § code
    The vault 108Multi-agent designs 62sgit 91

Decisions (1)

  • decisionThe CLI team fixed pull on the vault where the agents reported it: blobs now come in batches of 50 with 16 requests in flight, and past a long gap the client lists the store and sweeps what is missing.“blobs now come in batches of 50 with 16 requests in flight” § session
    sgit 91Vault design 48
