# v0.13.37: @newsroom.writer: the delegation record

**[The delegation record](../../articles/the-delegation-record.html)**: RiskMandate's go-to-market plan.

- **One chain, once.** From an existing business requirement to evidence that still holds after a change.
- **The six-part record.** Requirement, delegation, control mapping, evidence, remaining gaps, change conditions.
- **A rule for people is not yet a delegation.** Extract it, list the ambiguities, approve the delegation.
- **Three stages and a small first customer.** Immediate value, maintenance value, repeatability.
- **Pilot zero, our own inbox.** Gmail has no permission that allows drafting without sending.

A brief for the agent that maintains the RiskMandate sites is in admin/notes/brief-riskmandate-sites-the-delegation-record.md.
