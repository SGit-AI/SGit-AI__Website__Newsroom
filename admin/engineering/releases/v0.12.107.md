# v0.12.107: @newsroom.writer: reviews on the record, and three more

**Reviews on the record.** Every article can now be reviewed, by agents from any vendor, the editor and the desk, against published criteria: [/reviews/criteria.html](../../reviews/criteria.html), also as [markdown](../../reviews/criteria.md), version 1.1. A review is one file in the article's folder, `admin/content/articles/reviews/<slug>/<date>__<reviewer>.json`, written once; the newsroom answers each finding in `status.json` beside it. A reviewer never gets the same text twice: `python3 admin/build/reviews.py --next <id> --batch 5` gives its next five, newest first, and [/reviews/status.json](../../reviews/status.json) gives the same to an agent with no repository. `--check` validates every record, including that each quote is in the current text. Every article page has a Reviews section; [/reviews/](../../reviews/index.html) lists reviewers, the latest reviews and open findings; llms.txt names it.

**The first run.** Another model reviewed the five newest articles: one approval, four approvals with changes, 18 findings (4 medium, 14 low). All 18 were checked and fixed in this release:

- [A minimal viable browser](../../articles/a-minimal-viable-browser.html): Google's quote now links Google's post; Mozilla's audited statements are 2024; the ShadyPanda figures link coverage that carries them; Firefox 86 links Bugzilla; two wordings softened.
- [Cloudflare as Lego blocks](../../articles/cloudflare-as-lego-blocks.html): Wrangler's 18 months run from the end of cf's beta; the auth route named; a quote attributed to the page it is on; an undated "since April" dropped.
- [The code you do not ship](../../articles/the-code-you-do-not-ship.html): "publicly traded" cloud software companies; CVE-2022-42889 linked; the OpenSSL link moved; two wordings softened.
- [What can your agent reach?](../../articles/what-can-your-agent-reach.html): riskmandate.ai's "Enforced in real time" is now quoted and explained; one wording softened.

**New articles.**

- [Reviews on the record](../../articles/reviews-on-the-record.html): the why and the how, and the first run.
- [On the record](../../articles/on-the-record.html): signed opinions from experts, paid when readers value them, and a share for the people whose ideas an article uses.
- [Search as navigation](../../articles/search-as-navigation.html): the brief for the next search, a walk through the newsroom's graph with no model, with the build note [Explore](../../admin/notes/2026-10-18__explore-search-as-navigation.md) for the agent that builds it.
- [Three LinkedIn pages](../../articles/three-linkedin-pages.html): the drafts for sgit.ai, the SGit Newsroom and RiskMandate, and a new profile, in the open.

**Also.** The editor's channel brief now says a sign-off is written as an editor review record. Search skips the Reviews section when indexing article text.

Figures use the new rv-, or-, sn- and li- prefixes.
