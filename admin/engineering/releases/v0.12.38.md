# v0.12.38: @newsroom.writer: The minimum code below

A new article written here, from a voice memo after a conversation at Chainguard's event: container security from the top down, asking at every layer for the minimum code below that the layer above needs. Measured for the article on sgit 0.21.0 and its dependencies: a CI-style use case run under coverage across the whole dependency tree, then run again from a tree of only the files that ran (1,500 files to 428, Python source 4.72 MB to 1.98 MB, compiled code unchanged at 14.78 MB, 38% of statements in kept files executed; commands outside the use case failed; a compiled module coverage missed was caught by the tests). Corrections recorded: runtime minimisation already exists (SlimToolkit, RapidFort), and Chainguard's Custom Assembly only adds packages. Three figures.
