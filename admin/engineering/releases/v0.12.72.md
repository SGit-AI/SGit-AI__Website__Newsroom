# v0.12.72: @newsroom.writer: Scion and sgit

One new article written here from a voice memo.

Scion and sgit compares Anthropic's Scion, the source control that replaced Git in its monorepo after agents pushed merges past 30,000 a day, with sgit, read from Anthropic's post of 13 October and from sgit-ai 0.22.0's code. It sets out where they meet (immutable content-addressed objects, partial and on-demand fetches, compare-and-swap refs), where sgit differs (client-side encryption of everything, a dumb server, reads from any static host or CDN) and where Scion is ahead (server-side history, merge, blame and bisect, packing, proven scale), and corrects the memo where the code says otherwise. Measured on 0.22.0: a scoped clone in 4.2 seconds against 58.6 for the full one, and a full clone from a plain file server identical to the API's. Three figures.
