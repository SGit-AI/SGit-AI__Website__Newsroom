# v0.12.21: @newsroom.wire: R2 waits for the saved state

The first run of v0.12.20 in CI failed one check, R2 of the review test, which had passed twice on the same tree in the session: it waited a fixed 1.2 seconds for a charged page to save the meter's state before pushing a broken persona into it, and the runner was slower than that, so the meter's own save overwrote the set-up. The wait is now by condition, as the same test already does for the personas page (048). Nothing else changes. The deploy of v0.12.20 had gone out, since the deploy job needs only the validator; its tag is backfilled by this push.
