# v0.12.106: @newsroom.writer: less code, and the editor's channel

Four new articles and a wording check.

- [The code you do not ship](../../articles/the-code-you-do-not-ship.html): code is a liability; the worst vulnerabilities sat in features nobody needed; models make removing code safe; the minimal viable code path, and who gets paid to keep it small.
- [A minimal viable browser](../../articles/a-minimal-viable-browser.html): a small kernel and components loaded when needed, a browser for one agent as a prompt-injection defence, every extension in its own box, why Mozilla is well placed, and why the pitch is speed. It corrects the memo on Mozilla's revenue.
- [Cloudflare as Lego blocks](../../articles/cloudflare-as-lego-blocks.html): the developer platform mapped as small blocks for non-specialists, which models stay inside, and an sgit vault on Cloudflare: read-only with no code, read-write in 83 lines, tested locally in Cloudflare's runtime with the real client.
- [The editor's channel](../../articles/the-editors-channel.html): an editor key, an editor vault, a daily pass, and five audiences with five lanes; with a brief for the vault pane's agent, [admin/notes/2026-10-18__the-editors-channel.md](../../admin/notes/2026-10-18__the-editors-channel.md).
- A new trail, *less code*, joins the first three with [the minimum code below](../../articles/the-minimum-code-below.html).

**Wording.** Superlative self-claims, such as "the clearest example I have seen", rewritten in 20 articles, in their text, graphs or summaries. `admin/build/wording.py` now flags them, the article README lists the rule, and the leak scan fails a commit that adds one; phrases reviewed and kept go in `admin/build/wording-allow.txt`.

**Phones.** Code blocks in articles now scroll inside themselves instead of widening the page (one rule in `assets/themes/themes.css`); this also fixes [sgit in a CI pipeline](../../articles/sgit-in-a-ci-pipeline.html) at 390px.

Figures use the new nc-, mb-, cw- and ec- prefixes.
