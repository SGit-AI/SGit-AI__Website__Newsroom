# v0.12.108: @newsroom.writer: a section for publishers

**Sections.** The newsroom as one audience reads it, kept current by rule. The first is [For publishers](../../sections/publishers/index.html), linked second in the Newsroom menu on every page: five pieces to start with, chosen by the editor; the latest for publishers, marked new for a week; the features a publisher can use today, each with when it shipped and the article that explains it; and every relevant article placed into four streams (how news gets paid for, answers to the industry, readers and personas, how this newsroom runs), each saying which rule placed it. [All sections](../../sections/index.html) lists them; llms.txt names the hub.

- `admin/content/sections/publishers.json`: the editor's words and the rules, written against `articles/find.json`; `exclude` and `slugs_not` carry the editor's exceptions with their reasons.
- `admin/content/features.json`: a register of what the site can do, one entry per feature, published as [sections/features.json](../../sections/features.json). A feature is added in the release that ships it.
- `admin/build/sections.py`: places every article, writes each section's page and its JSON twin ([sections/publishers.json](../../sections/publishers.json)), and prints the near misses. Runs in the release after `desks`.

**The article.** [A section for publishers](../../articles/a-section-for-publishers.html): where to send someone new, how the section keeps itself current, and what building it showed about the classification.

Figures use the new sx- prefix.
