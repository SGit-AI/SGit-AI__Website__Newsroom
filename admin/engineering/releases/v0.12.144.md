# v0.12.144: @newsroom.writer: the no-server startup

**[The no-server startup](../../articles/the-no-server-startup.html)**: a blueprint, for founders and the agents that work with them, of products with no server and no database of their own in phase one. A folder of HTML, CSS and JavaScript, native web components and vendored libraries, running offline and anywhere; the user brings the AI key, the storage and the passkey; the company is never in the line of a request. Ten principles, an infographic studio as the worked example, the gaps on the providers' side as their documentation reads today, how to build it with agents and an explorer as the first hire, how to charge for it, and a twelve-step checklist for agents. Four figures.
