# v0.12.13: the bar's limit moves to 1280, because fonts differ between machines

v0.12.12's test failed on its first run in CI: the bar took two rows at exactly 1200px on Ubuntu's fonts, a few percent wider than the fonts of the machine the sweep ran on, and the tools row on a phone overflowed a long page by a few pixels for the same reason. A limit measured on one machine's fonts is not a limit. The collapse is now at 1279, one row from 1280, a common laptop width, with the difference as slack; the tools row wraps on a phone; the test sweeps a short page and goes down to 360. The article says so, at v1.1.0, and card 037 records it.
