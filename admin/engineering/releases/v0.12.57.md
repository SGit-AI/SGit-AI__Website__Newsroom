# v0.12.57: @newsroom.writer: The tokens hook, and Wardley's names corrected

One new article written here from a voice memo, and a correction to two earlier ones.

The tokens hook proposes a token behaviour policy, observe mode first, and builds it as a Claude Code hook of 132 lines with a policy file: it reads only the new lines of the session transcript, counts each response once, prices it by model and shows the user a box of cache reads, writes, context and cost. Asked through a prompt, the model said it could not see its usage; with the hook it reported exact figures one turn behind, at about a millisecond a call. Building it found that this session's own status report counted each response two or three times, because the transcript repeats usage on every content block; the report now counts each message id once. It also found that the transcript carries the system prompt and every tool definition in this version. With the other tools compared and a brief for tokens.hook.sgit.ai. Three figures.

Corrections: The citizen developer is good news and The eyeballs get cheap used Simon Wardley's earlier names, pioneers and settlers. Both now use his current ones, explorers, villagers and town planners, and the citizen developer article cites his 2023 post instead of the 2015 one; its figure was redrawn.
