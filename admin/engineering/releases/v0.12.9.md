# v0.12.9: ask the site

*Ask*, beside *Search* (033). The question is searched with the same index; the best passages, numbered, go to a model with one instruction: answer only from them and cite them by number. The answer comes with the passages under it, each linked to its page and section, and the page says which model answered and what was sent.

The model is Chrome's built-in model where the browser has it, on the reader's machine with nothing sent; otherwise the reader's own OpenRouter key, kept in the tab unless they ask to keep it, sent to openrouter.ai and nowhere else. With neither, the passages alone. A question can be a link: `?q=…&ask=1`.

CI runs eleven test files.
