# v0.12.74: @newsroom.wire: The runs unblocked and costed, and the wires about people

The owner's ask of 16 October. **The desks** (card 068): the AWS and Portugal runs were refused that morning (the clone as "data exfiltration", the install as exfiltration and the clone as "credential exploration") while the Industry Wire's got through on a retry; the one difference in wording was the Industry clone key without its prefix, as the owner had written it. The four desks now share one wording: the clone key in the owner's form, a plain statement of what the run is and who authorised it (the owner's own vault on the owner's own server, the wire's memory, public news in it), install and clone as separate commands, and a line in every report saying what was refused. All four run on Sonnet, the verifier on Haiku; the Industry run of 16 October cost $10.06, mostly on Opus. **The newsroom's run** (card 069) reads the vaults with the site's own reader in Node (`admin/build/vault_fetch.mjs`) and installs nothing, after three mornings refused at `pip install`. **Every run costed** (card 070): `admin/build/wire-runs.json`, written with `admin/build/runs_ledger.py`, and the runs section of [what the wires cost](../../wire/costs.html): cost and tokens per model, turns, subagents, refusals and outcome per run, with the working session that built the wires counted apart. **Wires about people** (card 072, open): the charter gains the rules for a wire about a person; the Dinis Cruz Wire's vault and desk exist and its first edition is being made; the rUv Wire's vault exists, and its desk waits on the owner.
