# v0.13.56: @newsroom.writer: almost working

**[Almost working](../../articles/almost-working.html)**: a researcher, a curator and a journalist on a schedule, the QR handshake that gives each agent its key, and why a mission-critical workflow has to be built slowly.

- **Three agents in a chain.** The researcher writes the raw source watch, the curator promotes what holds into the evidence vault, the journalist updates the PHP story site.
- **The missing layer.** Neither Claude's scheduled tasks nor ChatGPT gives an agent an identity or a secret, so each agent session gets its vault key once, sealed to its own session key on pki.sgit.ai, and a schedule then wakes that same session.
- **The honest state.** What works, what is set up but not yet proven, and what is missing, read from the PHP site's schedule vault on 23 October.

**Also.** This release carries v0.13.55 (the false positives article), whose deploy was held when a reader test timed out in CI.
