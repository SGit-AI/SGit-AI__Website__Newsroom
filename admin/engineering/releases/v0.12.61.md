# v0.12.61: @newsroom.writer: The scripted talk

One new article written here from a voice memo.

The scripted talk proposes giving a short talk as a timeline that plays on a clock, and builds the first version: one HTML file that plays a file of beats, each with a slide and the words to say, with builds, a typed terminal that prints the recorded output of the real run, tables revealed row by row, video, a presenter view and a rehearsal mode, tested in Chromium. It traces the idea through two talks published as vaults on sgit.ai, the Black Hat Europe 2025 keynote, whose slides are one JSON file, and the VoiceDebrief pitch, which added timings and a presenter. The memo's "clog motion" is Claude Motion, in beta since 8 October 2026; a second garbled name is read as Manim or Remotion and marked as a guess. The first timeline is the five-minute demo for ruv.sgit.ai. Three figures.
