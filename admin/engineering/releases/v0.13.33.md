# v0.13.33: @newsroom.writer: the reading account, as built

**[The reading account, as built](../../articles/the-reading-account-as-built.html)**: one page that says what runs today and what is proposed.

- **Built.** The meter, £5 of starting credit, Stripe top-ups since 11 October, and the account in the reader's own vault: one file per device, a balance across devices, merged devices, notes, a lane any browser can write to, and a server that sees only ciphertext.
- **Proposed.** Payments checked against Stripe afterwards and signed; one account across our sites.

**[The user keeps the meter](../../articles/the-user-keeps-the-meter.html)**, corrected: it said the credit was kept in the browser and that nothing was built; the account is carried into the reader's vault, and only the billing vault is a proposal.
