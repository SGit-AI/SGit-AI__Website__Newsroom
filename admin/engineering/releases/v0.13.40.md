# v0.13.40: an investigation, the PHP flaws, and its evidence vault

**[The PHP flaws](../../php-flaws/index.html)**: a new section following the critical PHP vulnerabilities disclosed on 22 October 2026, while the story develops.

- **The page.** What is known, each point with its source; what is not known; the timeline as each source dates it; the claims as reported, confirmed, disputed or unverified.
- **The evidence vault.** A private sgit vault that several agents write to. Each source has dated captures (the raw page, the rendered page, the text, a full-page screenshot and the headers), and each file is hashed at capture. Per-agent files mean the agents never conflict.
- **What is published.** The [sources page](../../php-flaws/sources.html) lists every capture and its sha256, not the captures: they are third-party pages.
