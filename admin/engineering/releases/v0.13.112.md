# v0.13.112

@newsroom.writer: new article, "What sgit does that Git does not": sgit's ten releases between 3 and 27 October, each a bottleneck fixed, with the measured speed-ups (a one-file commit on 76,000 files from 29 minutes to 4.6 seconds, a pull on 228,000 files from 566 to 31.7 seconds), where the ideas came from (MGraph-DB, Memory-FS, caching on content addresses, the writer pays), and an honest four-way map against Git: what Git has no equivalent for, what Git has too, where Git is ahead, and what is next. Four figures of our own, two from cli.sgit.ai, summaries and a graph.

Also in this release: admin/build/test_review_vault.mjs (from v0.13.111) moved HOME for sgit pki's key store, which hid the runner's pip --user install of sgit-ai, so the deploys of v0.13.111 and v0.13.112 failed with "No module named 'sgit_ai'". The test now pins PYTHONUSERBASE to the real home's before it moves HOME, as test_vault.mjs already noted. The first push of this release also lacked the "site " prefix the tagger reads, so it is re-committed here under the release's own subject.
