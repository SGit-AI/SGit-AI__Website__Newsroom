# v0.12.15: The policy draws the liability line, and sgit.ai's moved banner cut on import

A new article written here, *The policy draws the liability line*: an answer to Ralf Thomas's LinkedIn post on agent accountability. The shell game works because nothing is written down between "allow" and the failure; an Agent Behaviour Policy's explicit prohibitions, still mostly hope, are the evidence that moves liability between deployer and vendor when broken; and every agent in a loop should take a policy beside its prompt.

sgit.ai v0.7.87 started phase one of retiring its copy of the newsroom: every moved page there carries a banner pointing here, and every markdown twin a first line saying so. The import cuts both (item 14 in `sync_newsroom.py`), and stops if a page carries the banner more than once, as sgit.ai's agent asked in its briefing.

Built first as v0.12.14, which another session released at the same time; re-released under the next version, on top of it.
