# v0.12.150: @newsroom.writer: no negative framing

**[A trusted framework for agentic finance](../../articles/a-trusted-framework-for-agentic-finance.html)**: "Not because anyone copied anything" is gone; the sentence now says only that we are working on the same problem. "That is fine too, as long as it is a graph" now says what graphs make possible: policies written as graphs, or readable as graphs, can be connected. The summary and the In short follow.

**[A small slice sets the price](../../articles/a-small-slice-sets-the-price.html)**: "The numbers are not invented; they are prices" is now "The numbers are prices, and this is a market."

**[The exit is when you sell control](../../articles/the-exit-is-when-you-sell-control.html)**: "None of that is wrong" is now "That can be exactly what the company needs"; and the right outcome "is easiest when it was agreed at the start".

The writing rules in the articles README gain one: no negative framing, no raising an accusation nobody made, no conditions on how others work.
