# v0.13.15: @newsroom.writer: Messaging-FS

**[Messaging-FS](../../articles/messaging-fs.html)**: a proposed encrypted messenger between vaults, built on append lanes and PKI.

- **Where we started.** The append lane was once called the inbox, and two agent teams messaged each other over it in September: it worked, and it was crude.
- **The idea.** Every user has a vault; a lane on each, and PKI on top, give an end-to-end encrypted messenger, on the web or the command line.
- **How one message travels.** Four separated capabilities, and a server that sees only ciphertext, size and time.
- **Messaging-FS and Email-FS.** One JSON file per conversation, or one file per email, next to Issues-FS.
- **What to build.** Mostly the September write-up's own recommendations, plus the schema and a lane command.
- **Two diagrams.** Drawn in Mermaid, with their source in the article.
