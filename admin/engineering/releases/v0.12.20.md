# v0.12.20: @newsroom.wire: the charter, the brief for the desks, one list per wire, day by day, the verifier at the story, who should know, and the morning run

The owner's voice memo of 13 October, after the OWASP and AWS wires went live: a schedule; a way to pass notes to the desks that write the vaults; subscribe to one wire alone; a page of what happened each day; contacts to tell about the wires, public so the outreach can be checked; a charter with the principles, the checks and balances and the rounds of agents; a third round that checks facts and independence; and a Portugal wire.

This release does this side's part. **The charter** (041) is published and binds every wire: facts first and analysis marked as the desk's, corrections that propagate, three rounds (the desk, the newsroom, the verifier) and what each enforces, what is never done, public by default. **The brief for the desks** (041) is a standing page a runbook reads at the start of every run, dated, newest first, carrying the memo's asks for the other side. **One list per wire** (042): the newsletter's lane and envelope with one header more. **Day by day** (043): every wire's releases and stories by date, from the vaults, and a Stories column on each sources page. **The verifier at the story** (044): the vault's factcheck records drawn where the story is read, and asked for on every run in a schema the page draws. **Who should know** (045): a reach page per wire, by organisation route only, under the contact rules this site already publishes, with the routes found on the OWASP Foundation's and AWS's own contact pages. **The morning run** (047): a routine on the owner's account, every day at seven, London.

Filed and blocked on the desks: a Portugal wire (046), one config file away once its vault exists.
