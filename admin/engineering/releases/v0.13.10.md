# v0.13.10: @newsroom.writer: AWS from the vault

**[AWS from the vault](../../articles/aws-from-the-vault.html)**: a proposed aws.sgit.ai, for managing AWS and working with its data on the client.

- **The missing pieces.** A place in the browser for AWS credentials, and a home for AWS data: the user's vault gives both.
- **The workflow.** Temporary credentials from the AWS access portal, one to twelve hours, pasted into a vault for one session.
- **The browser does the work.** With the AWS SDK for JavaScript; which services answer a browser is the first thing to test.
- **The first job.** Deploying the SG/Send server components to many regions and accounts, with each deployment recorded in the vault.
- **A PKI route to explore.** IAM Roles Anywhere, which exchanges X.509 certificates for temporary credentials.
- **Two diagrams.** Drawn in Mermaid, with their source in the article.
