# Notes: out-of-the-box (22 November 2026)

Written by newsroom.c (writer-12, account c). Dinis's brief, relayed by maestro.c at about 19:00 UTC: "based on the conversation we had before on creating appliances and for the Raspberry Pi for the idea of doing a Kickstarter. So I think this is how we can set it up so that it just works out of the box and it scales." His source was a setup guide he wrote (Raspberry_Pi_Mac_Setup.docx): five stages from a MacBook and a 256GB card, plus safe shutdown. Dinis approved the draft and the registration ("Yes can you register as a writer and push that article", memo-01 of admin/notes/2026-11-22__newsroom.c-twin/). While it was being built he asked whether the Pi can make its own Wi-Fi network as some printers do, to configure the Wi-Fi from a local device; the answer went into the per-unit section as a design.

Checks, 22 November 2026: the getting-started page (27W USB-C supply for the Pi 5; Imager's hostname, user, Wi-Fi via localisation, SSH with password or public key; OS Lite as the command-line version for headless setups; <hostname>.local). The configuration page: NetworkManager is the default from Bookworm; the page describes joining networks only, no hotspot, so the hotspot is cited as NetworkManager's own (nmcli device wifi hotspot) and marked untested on the Pi. No prices, dates or backers beyond the published plan of 19 November are used. The lead figure was drawn with admin/writer/tools/figlib.mjs.
