# Memo 01, 31 October 2026: an augmented PDF viewer

Dinis's message to newsroom.writer, kept word for word.

> Now, can you write another article, research brief, which is connected to the augmented view, which kind of got me thinking, since we actually have the ability to do a lot of these things today, how hard would it be to create a JavaScript-based PDF viewer that has that augmented reality? Because PDF kind of sucks, right? PDF at the moment is weird format, it's static, you know, it doesn't have a lot of stuff. But if we are now looking at this sort of augmented reality, why can't we augment PDF, right? Why can't we have a PDF version, either compatible with others or a variation of it or something like that we can actually use to transmit these other capabilities? So the UI suddenly has a lot more data mapping, semantic graphs, and all that kind of jazz that, for example, we could present. So I guess my question is, how feasible would it be to create a custom PDF viewer that, you know, renders PDF, but also is able to handle all that augmented reality, which actually, thinking about it, probably doesn't even need to be on a PDF. The PDF just needs to have enough clues so that you can find it automatically for the user. Like, for example, QR code or links, we can be a lot more interactive from a user point of view. Yeah, I think it's worth exploring because I don't know a lot about PDFs. I know that there's a bunch of parsers. I know it runs on the browser, which is super powerful. Hopefully an open source project that we can extend. But yeah, so it'll be interesting to see what we can find out.
