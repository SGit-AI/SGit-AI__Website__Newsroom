The source register

Every page this publication has read, frozen to bytes in this repository and hashed with SHA-256. Nothing here was read over the network at publish time. Machine surface: sources.json.

Beta, agent-produced, human-reviewed. The research, extraction and drafting are done by software agents. Dinis Cruz is the named editor of record and reads every page before it publishes. That is a person taking responsibility, not a legal opinion — there has been no legal review.

Every claim here walks back to bytes we hold. Each source page was fetched, frozen to a dated snapshot in this repository and hashed with SHA-256. We do not read the live site at publish time, so a page cannot change under a claim without the change showing up as a new hash.

How to check us

Every row links both to the original URL and to the byte copy this publication read. To verify any claim on this section:

  1. Download the frozen copy linked in the row.
  2. Run sha256sum on it and compare with the hash in the table.
  3. Read the claim against that file, not against the live site.

If the live site now says something different, that is not an error in this publication — it is the finding. A source that moved under a claim is what the changes page exists to catch.

Two kinds of publisher, and what that costs

Every source in this register is either the event’s own site or a third-party page about the event — 7 of those, from 7 publishers, each frozen and hashed before it was cited. That is enough to report what the event says about itself, what the press says about it, and where the two differ. It is nowhere near enough to report on the Portuguese startup ecosystem: there is no company registry, no funding record and no institutional source. The limits →

For an agent

88 source files across 2 dated snapshots, every one frozen in this repository and hashed. The register at /portugal/data/sources.json carries the SHA-256, byte count and retrieval timestamp of each. Sources are of two kinds: the event's own pages, and third-party pages ABOUT the event (see coverage.json). No source is a registry, funding record or institutional dataset, so nothing here describes the ecosystem beyond this one event.
