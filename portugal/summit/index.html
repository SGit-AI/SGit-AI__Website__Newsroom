Startup Summit Lisbon 2026

2026-09-17 to 2026-09-18 at Unicorn Factory Lisboa, Beato Innovation District, Lisbon — 4 days away. Everything on this page is the event’s own published description of itself, read from frozen and hashed copies of its site. The event’s own site →

Beta, agent-produced, human-reviewed. The research, extraction and drafting are done by software agents. Dinis Cruz is the named editor of record and reads every page before it publishes. That is a person taking responsibility, not a legal opinion — there has been no legal review.

Every claim here walks back to bytes we hold. Each source page was fetched, frozen to a dated snapshot in this repository and hashed with SHA-256. We do not read the live site at publish time, so a page cannot change under a claim without the change showing up as a new hash.

We report what others have published. This publication originates no facts about any company or person, makes no assessment of anybody, and does not explain why a name appears or disappears from somebody else’s list. The full limits →

If you are named on this site — what is held about you, why, and how to have it removed without giving a reason: your data →

This publication does not assess this event. It reports what the event has published, links back to it, and re-reads it on a cadence so a reader can see what moved. Nothing here is a review, a recommendation or a warning.

What is targeted, and what is confirmed

The event's own wording separates what is TARGETED from what is CONFIRMED, and this publication keeps that separation. A target is a plan, not a result, and reporting one as the other is the most common way an event preview goes wrong.

The event publishes its own agent surface

The event publishes its own agent surface: an /ai-summary page for humans and /llms.txt plus /llms-full.txt for machines. That is rare enough on a conference site to be worth recording, and it is the same convention this network uses.

For an agent

Event facts are machine-readable at /portugal/data/event.json, and every field names the frozen source page it came from. Distinguish targets from confirmations: the event's own wording says targeting 2,000+ attendees and 150+ speakers planned, while the published speaker list names 64. Do not report a target as an attendance figure. The stage names differ between pages of the event's own site and this publication does not know which is current. The sponsor list is empty because none is published, not because none exists.
