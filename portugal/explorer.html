The files

Every file this section is built from — 111 of them, each with its size and SHA-256 — rendered, as a graph, and raw. If it is not in this list, it is not on this site. Machine surface: manifest.json.

Beta, agent-produced, human-reviewed. The research, extraction and drafting are done by software agents. Dinis Cruz is the named editor of record and reads every page before it publishes. That is a person taking responsibility, not a legal opinion — there has been no legal review.

Every claim here walks back to bytes we hold. Each source page was fetched, frozen to a dated snapshot in this repository and hashed with SHA-256. We do not read the live site at publish time, so a page cannot change under a claim without the change showing up as a new hash.

We report what others have published. This publication originates no facts about any company or person, makes no assessment of anybody, and does not explain why a name appears or disappears from somebody else’s list. The full limits →

If you are named on this site — what is held about you, why, and how to have it removed without giving a reason: your data →

What this is, and what it is not. The platform this site sits on has a vault browser that does exactly this for any vault, and the estate’s guidance is not to rebuild what the platform has. This section is not in a vault yet, so this page is the same idea rendered from a manifest: a folder on the left, and the file on the right in three views. When the section moves into a vault, the vault browser takes over and this page goes.

Query the files instead of opening them. Every JSON file listed here is loaded into a SQLite console and the graph into a SPARQL console, both running in your browser with no server; the loader spec names the file and field behind every column, so a cell in a result is one click from the file it came from.

newsroom.sgit.ai

    
News is failing not because there is too little information but because there is no walkable chain from a claim to its evidence, no way for a correction to reach what it disproved, and no way to pay the person who did the original work.
