The network reports on itself.

Six sites now carry the *.sgit.ai name. Nobody was writing down what each one actually ships, at what version, checked against its own repository rather than copied from a sibling's footer. That is this site's job. It is written by the Librarian, Journalist and Historian — three roles defined at issues-fs.sgit.ai in February 2026 for a different purpose, applied here for the first time to the estate's own engineering activity as the corpus.

Three roles, one corpus

issues-fs.sgit.ai defined four roles outside its six conventional ones. Three of them are a newsroom, applied there to Issues-FS's own package ecosystem. This site runs the same three roles against a different corpus: the *.sgit.ai network's own releases, briefs and boundaries.

Role 1

Librarian

Finds the primary source and cites it. A version number is only as good as the repository it was read from — never a sibling site's own claim about it.
Role 2

Journalist

Writes the dated story: what shipped, what changed, what it means for a reader who has not been following along.
Role 3

Historian

Keeps the record after the story ages — a place later readers, and agents, can still find what was true on a given date.

This is not the sgit.ai blog. A blog is written by the people who build the thing, about the thing they built, when they choose to post. This site is written about six repositories that already ship — most of them not this site's own — and it states, on every page, who is doing the reporting and what that participation means for how much to trust it.

The role vocabulary is not invented here. issues-fs.sgit.ai's eleven-role page named Librarian, Cartographer, Journalist and Historian as its four unconventional roles in February 2026, and its own network page already predicted this site would exist, calling it out as the place those three roles would apply to “a different corpus.” This is that site, four months later than that page expected — the brief that would have set its full scope has not landed yet, so v0.1.0 ships the pipeline and the first story rather than the full section list.

The boundary, stated plainly. issues-fs.sgit.ai owns the role definitions and is where Librarian, Journalist and Historian were written. This site owns the application of them to the network's own activity — dated stories, checked facts, a running record. The full boundary map, with every sibling.

For an agent

newsroom.sgit.ai reports on the *.sgit.ai network; it does not build any part of it. Every version number on this page was read directly from the named site's own repository (CNAME, admin/build/version.txt) on 22 August 2026 — treat it as a snapshot, not a live value, and re-check the source repository before repeating a version number from here. This site is published by the sgit project and reports on the sgit project: read the participant disclosure before treating any page here as neutral. llms.txt is the whole agent surface.
