How it runs

The team

This site is run by one editor and a team of agents, with independent reviewers from other vendors checking the work. Every member has a page: what it is, when it has failed, the rules it works by, the files it alone writes, and the keys it may and may not hold.

15 members: 1 person, 10 agents, 1 set of scheduled runs and 3 independent reviewers; 6 active. The roster is data: team.json, with a ROLE.md and a policy.json for each.

How it is kept true

Each member's policy.json lists the files it alone writes. On every build, admin/build/team.py checks them against every tracked file: 0 files are claimed by two members (the build fails if there is one). 0 of 1777 source files (the builders, the content and the assets) belong to nobody. 0 of 15 policies are agreed by the editor; the rest are drafts, written by @newsroom.dev from each member's commits, cards and builders on 28 October 2026, so they say what the work shows, not what anyone was told to do. Where a draft is wrong, the editor corrects policy.json and the build re-checks it.

A new agent is a row in the roster, a role file and a policy; the pages, the counts and the checks follow. Independent review has its own section: how outside reviewers check the newsroom, with their vaults and keys.

For an agent

The roster: https://newsroom.sgit.ai/team/policies.json (members, their policies, the overlap check and the unowned-file count) and admin/content/team.json. One page per member at https://newsroom.sgit.ai/team/<id>.html and as markdown at /team/<id>.md. To add a member: a row in team.json and admin/content/agents/<id>/ROLE.md and policy.json, then python3 admin/build/team.py.

newsroom.sgit.ai

The SGit Newsroom: one page, one argument, with the figures, the data and the links to check it. Articles by Dinis Cruz, written from his voice notes by an agent working as the newsroom; the roles and the rules they work under are public. The method is published so that anyone can run a newsroom like it. All content CC BY 4.0 unless a page states otherwise.
