Most of this vault is simulated, on purpose. The sample documents, the prices, the credit and every number in the business plan are invented or hypotheses. With no model connected, the studio uses a deterministic extractor in place of a model, so every feature works and every result replays. The blueprint makes the argument; the tour says what is real and what is simulated.

What is real, and what is simulated

PartIn this vault
The productReal: one HTML file, seven native web components, no framework, no build step, no server.
Drawing the infographicReal: the browser draws it as SVG, in four layouts and three themes.
Writing its contentSimulated by default, with a deterministic extractor. Inside the vault, the studio asks the host for a model through sg.llm; on a public read there is no key, so it says so and stays in simulation.
Your own keyWritten and checked in code, not yet run against a live key: OpenRouter's OAuth when the studio is served as its own page, or a pasted key, held in memory only.
Passkey, credit, cap, revenue shareSimulated, in the flow, with invented money.
Synthetic usersReal: three personas walked the studio in a headless browser before it was published, and all their checks passed.
